# Principal Components — Análise de Componentes Principais (PCA)

Repositório didático com códigos e bases de dados de apoio à execução da **Análise de Componentes Principais (PCA)**.

## Objetivo

Demonstrar etapas de preparação de dados, redução de dimensionalidade e interpretação de componentes em contextos de análise multivariada.

## Roteiro de estudo

1. Inspecionar a estrutura e a escala das variáveis.
2. Avaliar necessidade de padronização.
3. Calcular componentes principais.
4. Examinar autovalores, proporção de variância e cargas fatoriais.
5. Interpretar os resultados considerando o domínio e as limitações da amostra.

## Status

Material acadêmico de referência. Consulte os scripts e dados do repositório para identificar as implementações efetivamente disponíveis; o roteiro acima é conceitual e não implica que todas as etapas estejam automatizadas.
